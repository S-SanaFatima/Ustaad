Common Statistics Slip-Ups

Six patterns that cost marks across every statistics exam.

Distribution Choice

  • Calls the wrong distribution for the data
  • We screen each dataset for its distribution

Hypothesis Setup

  • Pens only the null hypothesis each time
  • We square null and alternative hypotheses together

Calculation Chains

  • Rushes middle steps in long calculations
  • We script each step through the calculation

Interpretation Wording

  • Phrases results without examiner-style language
  • We adjust phrasing to match examiner mark standards

Probability Confusion

  • Switches independent and dependent event rules
  • We gauge each event rule by context

Sample Bias Errors

  • Takes biased samples as fully representative
  • We flag bias before any sample is used

Diagram Sense

  • We scale and label every diagram correctly
